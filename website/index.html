مميزات منصة محراب

صُممت بعناية لتلبي جميع احتياجات إدارة الحلقات والمساجد بدقة وسهولة

📖

مصحف مجوّد وتسميع مسموع

مصحف كامل بالرسم العثماني مع أحكام التجويد الملوّنة، استماع لتلاوات خاشعة، ونظام تسميع ذكي يمنع تكرار الآيات للطالب.

📚

موسوعة السنة والمتون (+١٥,٠٠٠ حديث)

صحيح البخاري وصحيح مسلم كاملين، الأحاديث القدسية، والأربعين النووية، مع مسارات متقدمة لحفظ المتون والعلوم الشرعية.

🎁

بنك المكافآت والقسائم الإلكترونية

تحفيز الطلاب عبر نقاط الحفظ والحضور، واستبدالها بقسائم مشفرة بـ QR Code تُصرف فوراً عبر أمين الصندوق.

🎒

الرحلات والمستلزمات الذكية

جدولة الرحلات والأنشطة، استهداف المتميزين، وقائمة تحقق تفاعلية لما يلزم إحضاره مع كل طالب قبل الانطلاق.

📊

رصد الحضور ونسبة الالتزام

احتساب دقيق لنسبة انضباط الطالب وحضوره وتأخيره وغيابه، مع تقارير وإحصائيات تفصيلية للإدارة وأولياء الأمور.

📴

العمل الكامل بدون إنترنت (Offline-First)

سجّل التسميع والحضور بالمسجد دون الحاجة لأي اتصال، وتتزامن كل التعديلات تلقائياً في الخلفية عند توفر الشبكة.

🧕

خصوصية كاملة للقسم النسائي

استقلالية تامة وبيانات معزولة ومحمية برمز خاص للحلقات النسائية لضمان أعلى معايير الستر والخصوصية.

👥

واجهات متخصصة لجميع الأدوار

لوحات تحكم متكاملة مخصصة لإدارة المسجد (٩ أقسام)، وللشيخ المحفظ (٧ أقسام)، وللطالب وولي الأمر، ولأمين الصندوق.
