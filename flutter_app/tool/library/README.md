# كتب المكتبة السحابية

نصوص الكتب ليست داخل التطبيق: كل كتاب يُستورد كاملاً من مصدره، يُقسَّم إلى
أجزاء، ويُرفع إلى Supabase. التطبيق يجلب الفهرس ثم الأجزاء التي يحتاجها فقط.

## إضافة كتاب (بلا إصدار جديد)

```bash
node tool/library/add_book.mjs search "مدارج السالكين"   # يعرض الطبعات وأرقامها
node tool/library/add_book.mjs add 199                   # يضيفه ويستورده ويرفعه
```

`add` يأخذ العنوان والمؤلف والتصنيف من بيانات المصدر، ويكتب المدخل في `books.json`
ثم يرفع النص كاملاً. يمكن تحديد أي حقل: `--id`، `--title`، `--short`، `--author`،
`--category`، `--description`، `--color`، `--order`. و`--dry-run` يطبع المدخل ولا يكتب شيئاً.
عند وجود أكثر من طبعة اختر المحقَّقة الأكمل، واكتب `--description` نبذة حقيقية عن الكتاب.

الكتاب يظهر عند المستخدمين حين يفتحون المكتبة (المزامنة تجري عند فتحها إن مضت
خمس دقائق على آخر مزامنة) أو عند السحب للتحديث. والتصنيف الجديد يظهر رفّه وزرّه
تلقائياً: التطبيق يبني التصنيفات من الفهرس نفسه.

الأداة تحدّث أيضاً `lib/data/library_cloud_seed.dart`، وهي نسخة الفهرس التي يحملها
الإصدار القادم ليظهر الرف من أول تشغيل؛ لا حاجة لإصدار من أجلها.

## تحديث كتاب أو إخفاؤه

عدّل مدخله في `books.json` ثم:

```bash
node tool/library/import_books.mjs --only <id>   # كتاب واحد
node tool/library/import_books.mjs               # الكل (ما لم يتغيّر لا يُرفع)
node tool/library/import_books.mjs --dry-run     # بناء محلي في build/library_import بلا رفع
node tool/library/add_book.mjs remove <id>       # يخفيه من التطبيق ("published": false)
```

لا تحذف الصف من الجدول مباشرة؛ الحذف النهائي لا يصل إلى الأجهزة إلا في المزامنة
الكاملة الأسبوعية، أما إلغاء النشر فيصل في أول مزامنة.

## المصادر

- `{ "turath": 12028 }` — رقم الكتاب في المكتبة الشاملة (كما يظهر في رابط
  shamela.ws/book/12028). النص يُنزَّل مرة واحدة إلى `.cache/`.
- `{ "file": "path/book.json" }` — ملف محلي بالشكل:

  ```json
  {
    "info": "بيانات الطبعة",
    "pages": [{ "text": "...", "vol": "1", "page": 5 }],
    "headings": [{ "title": "باب كذا", "level": 1, "page": 1 }]
  }
  ```

  `headings[].page` رقم الصفحة في مصفوفة `pages` (يبدأ من 1). داخل النص: سطر
  `_________` يفصل المتن عن الحواشي.

## رمز الاستيراد

الكتابة في جدول `library_books` وفي الـ bucket `books` مرفوضة للمفتاح العام وحده؛
تحتاج الترويسة `x-library-ingest-token`. الرمز في `tool/library/.ingest-token`
(خارج git) أو في المتغيّر `LIBRARY_INGEST_TOKEN`، وقاعدة البيانات تحفظ بصمته فقط.

على جهاز جديد:

```bash
node tool/library/make_ingest_token.mjs    # ينشئ الرمز ويطبع بصمته
```

ثم في SQL Editor:

```sql
insert into private.library_ingest_tokens (token_sha256, label) values ('<البصمة>', 'اسم الجهاز');
```

لإبطال رمز: احذف صفّه من `private.library_ingest_tokens`.

## شكل التخزين

```
books/v2/<id>/<rev>/index.json   عدد الصفحات، بدايات الأجزاء، العناوين، أرقام المطبوع، المجلدات
books/v2/<id>/<rev>/c<n>.json    { "from": <أول صفحة>, "pages": [{ "t": "المتن", "f": "الحواشي" }] }
```

`rev` يزيد مع كل تغيير في المحتوى ويدخل في المسار، فالملف المنشور لا يتبدل
محتواه أبداً ويُخزَّن عند القارئ بلا انتهاء صلاحية. بعد نجاح الرفع تبقى المراجعة
السابقة منشورة (لمن يقرأ الآن أو لم يزامن فهرسه بعد) ويُحذف ما قبلها؛
`--keep-old` يبقي الكل.

في المتن: السطر الذي يبدأ بـ `## ` عنوان، و`* * *` فاصل، و`(^١)` إحالة إلى حاشية.
